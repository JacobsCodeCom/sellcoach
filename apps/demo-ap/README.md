# Meridian · accounts payable example

This app is the **AP invoice desk demo** (Relay + fake Meridian ERP). It is an example company vertical from Challenge 01 (AI Apprentice), not the Mira product.

Run from the repo root:

```bash
pnpm dev:demo-ap
```

Opens on [http://localhost:3002](http://localhost:3002).

The product app is `@mira/web` (`pnpm dev:web`).
