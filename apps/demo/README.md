# Northlane · logistics example

This app is the **dispatch desk demo** (Relay + fake Northlane board). It is an example company vertical, not the Mira product.

Run from the repo root:

```bash
pnpm dev:demo
```

Opens on [http://localhost:3001](http://localhost:3001).

The product app is `@mira/web` (`pnpm dev:web`).
