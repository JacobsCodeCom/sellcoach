# Acme Ops · support escalations example

This app is the **support ticket desk demo** (Relay + fake Acme Ops console). It is an example company vertical from Challenge 01 (AI Apprentice), not the Mira product.

Run from the repo root:

```bash
pnpm dev:demo-support
```

Opens on [http://localhost:3003](http://localhost:3003).

The product app is `@mira/web` (`pnpm dev:web`).
